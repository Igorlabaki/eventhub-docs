# Framework Core — EventHub

Memoria operacional viva do workspace multi-repo EventHub.

- comecar por `index.md` e `project/agent-entrypoint.md`;
- usar `BOARD.md` para decidir o proximo trabalho;
- usar `task-requests/` para demandas delimitadas;
- promover para `specs/` mudancas maiores, sensiveis ou multi-repo;
- manter detalhes historicos e analises extensas em `docs/`, ligados por `topics/`.

Bootstrap executado em 2026-11-02 a partir do codigo, manifests, schema Prisma e documentacao existente. Fatos atuais foram separados de recomendacoes e lacunas.
