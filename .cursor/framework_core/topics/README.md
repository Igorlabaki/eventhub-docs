# Topics — EventHub

Mapas curtos para entrar em uma area sem reler o sistema inteiro.

- `backend-api.md`: arquitetura, modulos e contratos HTTP;
- `frontend-application.md`: rotas, UI, estado e servicos;
- `data-and-migrations.md`: schema, integridade e evolucao MySQL/Prisma;
- `auth-and-security.md`: JWT, permissoes e superficies sensiveis;
- `integrations.md`: S3, e-mail, notificacao no banco, Web Push e Google Calendar;
- `delivery-and-known-gaps.md`: deploy, testes, observabilidade e backlog legado.

Topics documentam o estado atual. Mudanca futura entra por task-request, plan ou spec.
